## Doppar Documentation
You can find the online version of the Doppar documentation at [https://doppar.com](https://doppar.com)

## Contribution Guidelines
If you are submitting documentation for the current stable release of Doppar, please submit it to the corresponding version branch. For example, documentation for Doppar 3 should be submitted to the 3.x branch.

If your documentation applies to upcoming features or changes that will be included in the next release, submit it to the `master` branch instead.
